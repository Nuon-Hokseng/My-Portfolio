# Portfolio redesign — 25 November 2026

## Shipped scope

- Approved monochrome hero: outlined/solid name, original transparent portrait, concise developer role, 2.5 years of hands-on development experience, and real CV/profile links.
- The portrait starts monochrome on every device. A soft color spotlight follows mouse hover or finger contact/drag and fades out on leave, finger lift, or cancellation. Vertical scrolling and pinch zoom remain native. Reduced motion removes transitions. Pointer updates write CSS variables at most once per requested animation frame, without React state updates or an idle animation loop.
- Full recruiter-focused redesign: shorter content, grouped skills, work experience, compact education, real project summaries, volunteering, achievements, optional extras, and contact.
- Cambodia 4.0 outreach in **Kompong Thom, 18–20 November 2026**, teaching students and older adults about robotics and AI literacy. All four supplied images are represented; the HEIC was converted. Browser-ready WebP derivatives total about 757 KiB versus roughly 6.6 MiB of originals. Original files are preserved locally, unchanged.
- Gallery filters, full project descriptions/screenshots, the earlier Sala Dong and CFF Camp stories, teaching/achievement photo switching, and real CV access remain available.
- Quiz and game are code-split and mounted only when opened. Closing the game unmounts it and releases its animation/audio resources; offscreen/hidden-tab gameplay stops its drawing loop.
- Light/dark site themes, a custom vector `nh` monogram favicon with automatic browser theme variants, explicit white/dark SVG icons, Apple touch icon, and app manifest PNGs.
- SEO: specific title/description, canonical custom domain, Person/ProfilePage graph, honest current-student affiliation, updated share card, robots/sitemap, and the exact real CV filename. No search-ranking or indexing guarantee is implied.
- Removed a decorative font download and replaced the old large hidden-by-default section entrances with finite progressive enhancements over readable base content.
- Next.js updated from 16.4.3 to patched 16.4.6. Added reproducible lint and browser/accessibility test dependencies; no runtime motion library.

## Reproduce local checks

```powershell
npm ci
npm run lint
npx tsc --noEmit
npm run build
npm run start
# In another terminal; Chrome must be installed:
npm run test:ui
npm run test:motion
```

`scripts/check-portfolio.mjs` runs the production page at 320, 390, 768, 1024, and 1440 px in light/dark themes, checks actual image loading, portrait color interaction, filters, photo switching, native modal focus/Escape behavior, optional quiz/game, persisted theme, reduced motion, no-JavaScript navigation/content, metadata and icon endpoints, and axe WCAG A/AA checks at desktop/mobile widths. JSON and screenshots are written under `design/verification/`.

## Boundaries

- Browser emulation is not physical-device testing or a promise of perfect frame rate on every device. No physical iPhone/Android or Safari validation was available in this session.
- The existing CV PDF contents were not rewritten. Site copy is updated to 2.5 years; check the downloadable PDF separately before sending it to recruiters.
- Earlier design previews and original camera/source images are not required by the deployed page and are left local. Production uses only the four optimized outreach images.
- Git push, Vercel deployment status, and live verification must be reported separately; local build/test success alone does not establish a deployed release.

## Rollback

Revert the redesign commit on `main` and push the revert to trigger Vercel, or select the previous production deployment in Vercel. There are no database, account, or destructive data changes to reverse.

## Deployment-only regression caught and repaired

The first live check exposed a Windows/Linux filename-casing mismatch: the working directory displayed `Nuon_Hokseng_CV.pdf`, but Git's tracked filename is `Nuon_HokSeng_CV.pdf`. The shared `cvUrl` and sitemap now use Git's exact spelling, and the browser test checks the URL against `git ls-files` so Windows cannot silently mask this regression again. `PORTFOLIO_REPORT_DIR` allows live test evidence to be saved separately from the local report.

- Replaced the nearly imperceptible one-time reveal with section-specific choreography: staggered rising stats, fanning skill cards, opposing experience panels, timeline milestones, gently angled project cards, photo/achievement reveals, and a rising contact block. - `scripts/check-motion.mjs` samples actual changing transforms and final opacity, all eight post-hero sections, repeat visits, dynamic filters, hover feedback, reduced motion and browser errors on desktop and Pixel 7 emulation. It also records desktop and 4x-CPU-throttled Android-emulation frame intervals as lab observations, not a physical-device frame-rate guarantee. Results: `design/verification/motion.json`.
- The UI regression now measures equal modal gutters on desktop, 390px/320px Android portrait and Android landscape, and verifies long details remain scrollable. The original CV, navigation, touch spotlight, project details and optional extras retain their regression coverage.
